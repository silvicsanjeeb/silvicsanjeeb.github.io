Overview

In this step-by-step tutorial, I’ll share how I build and deployed this my own website for free using few open source resources. By following these step-by-step methods, it is my hope that you can also build and deploy your own website just like me. You will need the following Opensource tools and some basic skills of using them.

Must:

  • R and R Studio
  • Very basics of Markdown (MD) language

Optional:

  • A GitHub account for automated deployment by git-push
  • A Google account for using Google Analytics features

Domain name:

  • Using free Netlify feature, you will get a domain name with netlify.app extension, for example sanjeeb.netlify.app
  • A Domain name for Nepal (.np) is freely available meeting certain criteria, learn more from here

Follow along the the links to major Steps on your left and Sub-steps within each Step on your right.
